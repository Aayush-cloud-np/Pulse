This folder is where the Progress page's Gallery section looks for photos.

Each gallery card checks for an image at a fixed filename first, and falls
back to a designed gradient card if that file isn't present — so the
gallery looks finished right now, and upgrades automatically the moment
you drop matching files in here. No code changes needed.

Expected filenames (any JPG/PNG/WEBP you rename to match will work):

  strength.jpg
  cardio.jpg
  hiit.jpg
  yoga.jpg
  cycling.jpg
  recovery.jpg

Recommended: portrait-oriented photos (roughly 4:5) work best with the
card's aspect ratio and cropping.
